# Итоговый отчёт: Анализ данных о питании в сетях фастфуда

**Автор:** Онищенко Павел Владимирович  
**Проект:** Дипломный проект «Инженер по большим данным»  
**Дата:** 2024

---

## 1. Цель исследования

Провести полный цикл анализа данных о питательной ценности блюд в крупнейших сетях фастфуда (McDonald's, Subway, Sonic, Arby's, Dairy Queen и др.) с загрузкой данных в PostgreSQL и созданием интерактивного дашборда.

## 2. Задачи

1. Загрузить данные о питании из CSV-файла в реляционную базу данных PostgreSQL.
2. Спроектировать нормализованную схему БД (справочники ресторанов и блюд, таблица фактов).
3. Реализовать систему аудита изменений с помощью триггеров и хранимых функций на PL/pgSQL.
4. Провести разведочный анализ данных (EDA) с визуализацией.
5. Построить интерактивный дашборд для бизнес-пользователя.
6. Сформулировать выводы и рекомендации.

**Ключевые признаки:** калорийность, содержание жиров, натрия, углеводов, белков, витаминов.

## 4. Методология

### 4.1. Работа с базой данных

- **СУБД:** PostgreSQL
- **Схема:** `pavel_onichtchenko`
- **Таблицы:** `restaurants`, `items`, `nutrition`, `fastfood_nutrition`, `audit_log`
- **Оптимизация:** созданы индексы по `name`, `restaurant_id`, `item_id`.

### 4.2. Система аудита

Реализована триггерная функция `audit_trigger`, которая автоматически логирует операции INSERT/UPDATE/DELETE в таблицу `audit_log`. Для чтения истории создана функция `fnc_audit(p_table_name VARCHAR)`.

### 4.3. Анализ данных

Использован стек Python:
- **pandas, numpy** — обработка данных
- **matplotlib, seaborn** — визуализация
- **scipy** — статистические расчёты

### 4.4. Дашборд

Построен с помощью **Plotly Express** и **Panel**. Опубликован через **ngrok**.

- Правосторонняя асимметрия: большинство блюд в диапазоне 300–700 ккал.
- Длинный хвост до 2 000+ ккал (крупные комбо-наборы).

## 6. Выводы

1. **Структура ассортимента:** большинство блюд имеют умеренную калорийность (300–700 ккал), но есть крупные позиции для семейных заказов.
2. **Питательные профили:** калорийность и жиры сильно коррелируют — это подтверждает, что большая часть калорий в фастфуде приходит из жиров.
3. **Здоровое меню:** салаты Subway значительно выигрывают по содержанию натрия и калорий, что можно использовать в маркетинге.
4. **Инженерная часть:** созданная система аудита позволяет отслеживать изменения в БД — это прототип production-решения для крупных сетей.

## 7. Ограничения и направления развития
