## 🎯 Цель проекта
Освоить полный цикл работы с данными: загрузка в реляционную базу данных, написание SQL-запросов, создание триггеров и функций, анализ данных с помощью Python, построение интерактивного дашборда для визуализации ключевых метрик.

## 📌 Задачи
1. Подключиться к базе данных PostgreSQL и загрузить данные из CSV-файла.
2. Создать структуру таблиц и индексов для оптимизации запросов.
3. Реализовать систему аудита изменений с помощью триггеров и функций на PL/pgSQL.
4. Провести разведочный анализ данных (EDA).
5. Построить визуализации: bar chart, line plot, boxplot, heatmap, круговая диаграмма.
6. Создать интерактивный дашборд с помощью Panel и Plotly.
7. Опубликовать дашборд с помощью ngrok.

## 📊 Данные
**Источник:** `data/fastfood-nutrition.csv`

**Описание признаков:**

| Признак | Описание |
|---------|----------|
| restaurant | Название ресторана |
| item | Название блюда |
| calories | Калорийность (ккал) |
| total_fat | Общее содержание жиров (г) |
| sodium | Натрий (мг) |
| total_carb | Общее содержание углеводов (г) |
| protein | Белок (г) |

## 🔍 Этапы работы

### 1. Подключение к БД и загрузка данных
- Подключение к PostgreSQL через SQLAlchemy.
- Загрузка данных из CSV в DataFrame.
- Создание схемы `pavel_onichtchenko` и таблиц: `restaurants`, `items`, `nutrition`, `fastfood_nutrition`.
- Создание индексов для оптимизации запросов.

### 2. Система аудита изменений
- Создание таблицы `audit_log` для логирования изменений.
- Написание триггерной функции `audit_trigger` на PL/pgSQL.
- Привязка триггера к таблице `restaurants`.
- Создание функции `fnc_audit` для получения истории изменений.

### 3. Разведочный анализ данных (EDA)
- Топ-5 ресторанов по среднему содержанию калорий.
- Топ-5 блюд по содержанию белка.
- Топ-5 блюд с наименьшим содержанием натрия.
- Распределение калорий (гистограмма).
- Диаграмма рассеяния: калории vs белок.
- Тепловая карта корреляций питательных веществ.
- Boxplot распределения калорий по ресторанам.

### 4. Создание дашборда
- Построение интерактивных графиков с помощью Plotly Express.
- Создание дашборда с помощью Panel.
- Публикация дашборда через ngrok.
